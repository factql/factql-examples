# Embed a chat

One script and one tag gives your users a chat about your data, with answers, tables and charts.

1. In the FactQL app, create an **ask-only** key and add your site under Allowed websites. The chat refuses full-access keys, because anyone can read a key out of a web page.
2. Put the key in `index.html` and open it from a site on that list (`http://localhost` works for testing).

All options (wording, colours, `show-sql`, events) are in the [embed guide](https://docs.factql.ai/guides/embed-chat/?ref=github).
